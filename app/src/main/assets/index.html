Setup

  1. Enable AOD Enabler in LSPosed Manager.
  2. Scope: System Framework and SystemUI. Do not tick the AOD Enabler app, do not tick Settings.
  3. Reboot.
  4. AOD toggle should be in Settings > Display.

Debug

Run on a PC: adb logcat -s AODHook:*
