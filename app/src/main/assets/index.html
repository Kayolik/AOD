Setup

  1. Open LSPosed Manager and enable AOD Enabler.
  2. Scope: tick System Framework and SystemUI. Do not tick the AOD Enabler app. Do not tick Settings.
  3. Reboot the device.
  4. The AOD toggle should appear under Settings > Display.

Debug

Run on a PC: adb logcat -s AODHook:*
